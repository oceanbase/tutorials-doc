# 3.6 使用 JMeter 运行业务场景测试

JMeter 是由 Apache 软件基金会开发的一款开源的性能测试工具，基于 Java 平台构建，主要用于对软件应用进行负载和压力测试。JMeter 最初是为测试 Web 应用程序而设计的，但后来也扩展了其他的测试功能。我们可以通过 JMeter 来模拟业务 SQL 并分析数据库服务器在不同负载情况下的性能。

## 环境准备

您需先安装 JMeter 工具，具体方法可参见 [JMeter 文档](https://jmeter.apache.org/usermanual/get-started.html#install)。

使用 JMeter 测试 OceanBase 数据库性能前需先下载连接数据库的 Java 驱动，您可以从 [MySQL官网](https://downloads.mysql.com/archives/c-j/) 下载。推荐下载 `mysql-connector-java-5.1.47.jar`，下载后将文件放到 JMeter 的 lib 文件夹中，拷贝 lib 之后需要重启 JMeter。

## 测试方案

### 建表语句

请在 OceanBase 集群 MySQL 租户下业务账户执行如下 SQL。

```shell
CREATE TABLE account(id bigint NOT NULL AUTO_INCREMENT PRIMARY KEY
 , name varchar(50) NOT NULL UNIQUE 
 , value bigint NOT NULL
 , gmt_create timestamp DEFAULT current_timestamp NOT NULL 
 , gmt_modified timestamp DEFAULT current_timestamp NOT NULL  );
```

### 场景 SQL

此次测试简单模拟一个交易业务，SQL 示例如下：

```shell
begin ;
update account set  value = value - 7 , gmt_modified = current_timestamp where id = 174 ;
update account set  value = value + 7 , gmt_modified = current_timestamp where id = 165 ;
-- commit or rollback;
commit;
```

### JDBC 连接属性

![](../30.test-oceanbase-database/60.jmeter-test-03)

上图中有很多属性，都是一个连接池常具备的参数，详情参考网上关于 Java 连接池配置的经验。

您需注意以下参数：

* Max Number of Connections：连接池里的最大连接数。如果压测线程数远高于该值，那么压测线程可能需要等待这个连接池创建或返还数据库连接（即到 OceanBase 数据库的连接）给它，如果等不到可能会报错。在这个环节，客户端压测线程获取不到连接，不一定与 OceanBase 数据库有直接关系，在 Java 应用中同理。

3，最后一句是说：如果获取不到连接，可能是因为连接数不够大，不一定是因为 OB 数据库存在问题？ -->
* Transaction Isolation：数据库连接使用的事务隔离级别，OceanBase 数据库默认的隔离级别为读已提交（Read Committed）。

* Test While Idle：连接探活（keepalive）设置，对应用很有必要。有时候应用会提示数据库在一个关闭的连接上执行 SQL，进而报错，这是因为连接池中的数据库连接因为其他原因断开了。因此，数据库连接池通常都需要探活机制。此处因为压测场景基本无闲置连接，所以可以设置为 `False`。

* Database URL：数据库连接 URL 格式，例如 `jdbc:oceanbase://10.10.10.1:2883/test`。
<!-- 这里应该是配置数据库连接，而不是连接 url 格式？-->
* JDBC Driver Class：数据库驱动中的 Main 类名，需要按 OceanBase 数据库格式填写，例如 `com.alipay.oceanbase.obproxy.mysql.jdbc.Driver`。
<!-- 按照 OB数据库格式填写 是什么意思 -->
* Username：指用户格式，OceanBase 数据库的用户名格式比较特别，常用格式为 `用户名@租户名#集群名` 或 `集群名:租户名:用户名`，如 `tpcc@test#obdemo`。
